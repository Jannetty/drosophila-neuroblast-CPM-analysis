# Plan 24 — Figure 5 VOL-ABM-only variant

Date: 2026-08-04

## Goal

Produce an alternate version of Figure 5 that includes only VOL-ABM regulatory
dynamics, dropping VOL-PDE entirely and removing the now-redundant `VOL-ABM`
prefix from row labels and subplot titles. The two panels that compose
`fig5.svg` are the deliverable; they are assembled by hand in Inkscape. The
original PDE-inclusive Figure 5 pipeline must remain intact.

## Context

Figure 5 panels are generated by `docs/tex_draft/figure5_paper_figures.ipynb`.
`_build_fig5_svg.py` embeds exactly two of them into `fig5.svg`:

| PNG | Notebook cell | Current shape |
|---|---|---|
| `figure5_rotation_sweep_lineages.png` | 11 (`panel_d`) | 6 rows (2 reg dyn × 3 adhesion) × 4 relrot cols; row labels `"VOL-ABM\nJ=50"` |
| `figure5_connectivity_heatmap.png` | 13 (`panel_e`) | 1×2 subplots titled `VOL-ABM` / `VOL-PDE`, each 3 J × 4 relrot, shared colorbar |

`REG_DYN_ORDER = ["VOL-ABM", "VOL-PDE"]` is defined once in the constants cell
(cell 3); every regulatory-dynamics-dependent panel reads it. Panels A, B, C and
F (cells 5, 7, 9, 15) also read it, and cell 17 is dynamics-independent.

This mirrors the `fig4-nopde` variant (Plan 23) — same env-var toggle, same
`_noPDE` suffix convention, same hand-assembly workflow.

## Design

Single env-var toggle, edits confined to the notebook plus one Makefile target.

### 1. Constants cell (cell 3) — append

```python
import os as _os
_NO_PDE = _os.environ.get("FIG5_NO_PDE", "") not in ("", "0", "false", "False")
if _NO_PDE:
    REG_DYN_ORDER = [d for d in REG_DYN_ORDER if d != "VOL-PDE"]
_PANEL_SUFFIX  = "_noPDE" if _NO_PDE else ""
_RELROT_XLABEL = "Division plane reference" if _NO_PDE else "Apical axis rotation mean"
```

`os` is not currently imported in this cell (only in cell 17), so the import is
added here. Filtering the single shared global drops VOL-PDE from every
dynamics-dependent panel at once.

### 2. Suffix every figure output

Rewrite all 14 `FIG_DIR / "figure5_….png|pdf"` paths (cells 5, 7, 9, 11, 13, 15,
17) to `FIG_DIR / f"…{_PANEL_SUFFIX}.png|pdf"`. With `_PANEL_SUFFIX` empty in
normal mode, normal runs are byte-identical; a `FIG5_NO_PDE=1` run writes a
complete `…_noPDE.*` parallel set and never overwrites the originals.

Suffixing *all* outputs — not just the two composited panels — matters: panels A,
B, C and F also read `REG_DYN_ORDER` and would otherwise be silently overwritten
with ABM-only content by a variant run.

### 3. `panel_d` (cell 11) — lineages grid

- 6 rows → 3. The group-separator row is already gated on `i < n_reg - 1`, so it
  drops out on its own; `total_fig_h` recomputes from `height_ratios`
  (`3.0` units instead of `6.03`) and cell size is preserved.
- Row labels: `f"{reg_dyn}\nJ={adh}"` → `f"J={adh}"` when `_NO_PDE`.
- The `adh == 40` branch draws a two-line bold label plus a separate non-bold
  `(baseline)` line at offsets `+0.5 * line_h_fig` / `-1.0 * line_h_fig`, tuned
  for two bold lines. With a one-line label these become
  `+0.5 * line_h_fig` / `-0.5 * line_h_fig` so `(baseline)` sits snug under
  `J=40`.
- `fig_w`, `CELL_W`, `LEFT`, `RIGHT` unchanged → the 4 columns keep their current
  width.

### 4. `panel_e` (cell 13) — connectivity heatmap

Cell size and font sizes are held at their current values; the single heatmap
occupies roughly the left half of the old panel and `bbox_inches="tight"` trims
the remainder.

- 1×2 subplots → 1×1 (`len(REG_DYN_ORDER)` already drives `plt.subplots`).
- `ax.set_title(reg_dyn, …)` dropped when `_NO_PDE`.
- The axes-region right edge is derived rather than hard-coded, locking the
  per-subplot width fraction to what the two-subplot layout produces today:

```python
_SP_W_FRAC = (0.50 - 0.22) / (2 + 1 * 0.20)      # 0.127273 — current geometry
L, T, B, WS = 0.22, 0.91, 0.22, 0.20
n_sub = len(REG_DYN_ORDER)
R = L + _SP_W_FRAC * (n_sub + (n_sub - 1) * WS)  # 2 → 0.500000; 1 → 0.347273
```

  This requires moving the `n_sub` assignment above the layout block, which
  currently sits below it. `n_sub = 2` reproduces `R = 0.50` exactly, so the
  normal path is unchanged.
- The colorbar block already derives its geometry from `sp_w_frac`, so it follows
  automatically.
- `ax.set_xlabel("Apical axis rotation mean", …)` → `ax.set_xlabel(_RELROT_XLABEL, …)`.
  The variant label is corrected because the swept parameter is
  `DIV_ROTATION_IS_RELATIVE` (the division-plane reference vector), not the mean
  of the apical-axis inheritance rotation. The non-variant label is left as-is by
  request.
- `ax.set_yticklabels(… if ci == 0 else [])` still resolves correctly for the
  single subplot.
