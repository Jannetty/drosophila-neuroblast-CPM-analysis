# Figure 4 — no-PDE parallel variant

Date: 2026-07-20

## Goal

Produce an alternate version of Figure 4 that excludes the PDE-like growth
dynamics (`NB-PDE`, `VOL-PDE`), keeping all the same plots but with the PDE
data removed. The box-and-whisker section and the sample-lineage section should
end up the same total width when composited (so, with fewer columns, the lineage
columns come out wider than the metric subplots). The original PDE-inclusive
Figure 4 pipeline must remain intact.

## Context

Figure 4 panels are generated by `docs/tex_draft/figure4_paper_figures.ipynb`.
(The scaffolding script `_figure4_build_notebook.py` is stale — the notebook has
been edited directly since — so all edits go in the notebook, not the script.)

Panels and their shared globals:

- `panel_b` → `figure4_metrics_grid_panel` — 5 metric box-whisker subplots, each
  with `DYNAMIC_ORDER` on x (5 dynamics) × 2 VCV boxes.
- `panel_b_mean_sd` → `figS4_metrics_grid_mean_sd_panel` (variant).
- `panel_b_wt` → `figS_wt_metrics_grid_panel` (variant).
- `panel_c` → `figure4_representative_lineages_panel` — 2 VCV rows ×
  `PANEL_C_DYNAMICS` columns (5 dynamics).
- `panel_d` / `best_dynamic` → `figure4_best_vs_exp_panel` — 3-group comparison
  (Exp / best-VCV0 / best-VCV1); `best_dynamic` auto-selects among `DYNAMIC_ORDER`.
- `panel_d_mean_sd` → `figS4_best_vs_exp_mean_sd_panel` (variant).
- `panel_e` → `figure4_mudmut_exp_examples_panel` — percentile exp examples
  (no dynamics; PDE-independent).

`DYNAMIC_ORDER` and `PANEL_C_DYNAMICS` are defined once in the constants cell
(cell 2); every dynamics-dependent panel reads them.

## Design

Single env-var toggle, edits confined to the notebook.

### 1. Constants cell (cell 2) — append

```python
_NO_PDE = _os.environ.get("FIG4_NO_PDE", "") not in ("", "0", "false", "False")
if _NO_PDE:
    DYNAMIC_ORDER    = [d for d in DYNAMIC_ORDER    if d not in ("NB-PDE", "VOL-PDE")]
    PANEL_C_DYNAMICS = [d for d in PANEL_C_DYNAMICS if d not in ("NB-PDE", "VOL-PDE")]
_PANEL_SUFFIX = "_noPDE" if _NO_PDE else ""
_FIG4_B_WIDTH = 18.4 * (len(DYNAMIC_ORDER) + 0.2) / 5.2   # box panels scale with #dynamics
_FIG4_C_WIDTH = 17.4 * len(PANEL_C_DYNAMICS) / 5          # lineage cols scale with #cols
```

Filtering the two shared globals drops PDE from every dynamics-dependent panel at
once, including `best_dynamic`'s selection (now only NB-ABM / Vol-ABM). `_os` is
already imported in this cell.

### 2. Suffix every figure output

Rewrite each `FIG_DIR / "figureN_….png|pdf"` (and `figS…`) to
`FIG_DIR / f"…{_PANEL_SUFFIX}.png|pdf"` across all cells. With `_PANEL_SUFFIX`
empty in normal mode, normal runs are byte-identical; a `FIG4_NO_PDE=1` run
writes a complete `…_noPDE.*` parallel set and never overwrites the originals.

### 3. Width tuning

- `panel_b`, `panel_b_mean_sd`, `panel_b_wt`: `figsize=(18.4, 4.7)` →
  `figsize=(_FIG4_B_WIDTH, 4.7)`.
- `panel_c`: `figsize=(17.4, 7.5)` → `figsize=(_FIG4_C_WIDTH, 7.5)`.
- `panel_d`, `panel_d_mean_sd`, `panel_e`: unchanged (fixed group counts).

Normal mode reproduces the original widths exactly (5 dynamics → 18.4; 5 cols →
17.4).

### 4. Makefile

Add a `fig4-nopde` target that runs the notebook with `FIG4_NO_PDE=1` to
regenerate the no-PDE panels (panels only — no compositor).

## Out of scope

- Panel A (schematic; no PDE data).
- SVG compositing / `fig4_noPDE.svg` — assembled by hand in Inkscape by the user.
- The stale `_figure4_build_notebook.py`.
